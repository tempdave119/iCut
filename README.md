# iCut

## 项目简介

macOS 上的截图与贴图工具，参考 Snipaste：按一下快捷键即可框选屏幕内容，确认后图像进入剪贴板；需要对照参考时，点工具栏图钉按钮把它变成置顶、可拖动的浮窗，用来临时摆放或快速比对。

## 目标

- 打通「快捷键唤起 → 框选 → 复制到剪贴板 + 贴图浮窗」的最小闭环，响应速度与操作直觉对齐 Snipaste。
- macOS 优先；Windows 版为可选后续项（P3），独立实现。
- v0.2 迭代：设置面板、可选自动保存、OCR 文字识别；v0.4 新增剪贴板历史。

## 核心功能

当前版本：v0.4.2 已发布。

- 菜单栏常驻，无 Dock 图标；重复启动不会产生第二个实例
- 全局快捷键唤起截图（默认 ⌘⇧2，可在设置面板修改）
- 多屏冻结截取 + 鼠标拖拽框选（选区压暗遮罩、实时像素尺寸、8 个调整手柄）
- 窗口智能识别：悬停高亮窗口，单击选中整窗
- 截图工具栏：形状（矩形/椭圆/直线/箭头）、画笔、文字、马赛克、序号；颜色按钮展开调色板；撤销、识别文字、保存 PNG、贴图、取消、确认
- 确认后自动复制到系统剪贴板；截图确认/取消后自动恢复原应用，TextEdit、微信等可直接 ⌘V；工具栏图钉按钮单独把选区贴成浮窗
- OCR 文字识别：选区或贴图上识别中英文，结果可编辑后一键复制（系统 Vision 本地识别，不联网）
- 长截图：框选固定区域后自行滚动页面，自动拼接成长图（行指纹重叠匹配，不模拟滚轮）；条带使用独立位图，慢滚长页面时内存更稳定
- 贴图浮窗：置顶、跨 Space 可见、拖动、滚轮缩放、⌥+滚轮调透明度、右键菜单（复制 / 识别文字 / 保存 / 透明度 / 旋转 / 关闭）
- 截图时自动隐藏已有贴图，完成或取消后恢复
- 设置面板：快捷键、工具栏位置、自动保存、开机自启、版本信息；两个页签支持滚动
- 剪贴板历史：默认关闭；开启后记录复制过的文本、图片与文件路径，本地 AES-256-GCM 加密存储；支持搜索、回填、单条永久保留、保留期与容量预算、一键清空；热键可自定义；加密异常可重试或重建密钥（清空历史）
- 可选自动保存：默认关闭；开启后确认截图按命名模板（默认 `iCut-{timestamp}`，如 `iCut-261111220531`）写入指定目录，重名自动追号
- 可选开机自启：默认关闭；开启后登记为系统登录项，登录即自动打开（需系统批准时提供入口）

后续规划：P3（Windows 版）暂未启动。

## 快速上手

### 环境要求

- macOS 13.0 及以上（开发机为 macOS 13.7.8 / Intel）
- Xcode Command Line Tools（Swift 5.8+），**不需要完整 Xcode**

### 安装（下载安装包）

最新版本见 [Releases](https://github.com/tempdave119/iCut/releases)。dmg 双击挂载后，把 `iCut.app` 拖进卷内的 `Applications` 快捷方式；旧版 zip 解压后直接拖入 `/Applications`。

安装包为 ad-hoc 签名、未经 Apple 公证，首次打开会被 Gatekeeper 拦截：在 Finder 里右键 `iCut.app` 选「打开」，或执行：

```bash
xattr -dr com.apple.quarantine /Applications/iCut.app
```

### 开发构建（本地验证）

```bash
./scripts/build-app.sh             # 编译 + 组装 + ad-hoc 签名，输出 dist/iCut.app
./scripts/build-app.sh --universal # arm64 + x86_64 双架构（CI 使用，本地也可跑）
./scripts/build-app.sh --dmg       # 额外产出 dist/iCut-<版本>.dmg
./scripts/run-tests.sh             # 单元测试（自建 runner，断言失败非零退出）
open dist/iCut.app                 # 启动
```

产物只出现在 `dist/`（编译中间文件在 `build/`），都不参与版本控制。**发布安装包不在本地构建**，统一由 GitHub Actions 产出；本地打包的唯一作用是拿到真实 bundle 身份，以便验证屏幕录制权限。

说明：本机只装了 Command Line Tools，没有 Xcode 的 `Platforms` 目录，`swift build` / `swift test` 会因缺少 `PlatformPath` 失败，因此构建直接用 `swiftc` + `lipo`，不依赖 SwiftPM。

### 授予屏幕录制权限

1. 首次触发截图时，应用会提示需要「屏幕录制」权限。
2. 打开「系统设置 → 隐私与安全性 → 屏幕录制」，勾选 iCut。
3. 退出并重新启动 iCut，权限才生效。

若列表里明明已勾选却仍提示授权：ad-hoc 签名每次重新构建都会改变代码哈希，系统会当成新应用。处理方法是在列表里取消勾选 iCut，再重新勾选，然后重启应用。

开发机建议在「钥匙串访问 → 证书助理 → 创建证书」中建一个自签名代码签名证书 `iCut Dev Signer`，`scripts/build-app.sh` 会自动优先使用它；证书签名下重建不再触发重新授权。CI 上没有该证书，会自动回落到 ad-hoc 签名。

> 请勿直接运行 `build/` 下的裸二进制验证截图：那样进程没有 bundle 身份，TCC 授权会落到终端上。

## 使用方式

1. 按全局快捷键（默认 ⌘⇧2，可在「设置…」里修改）唤起截图，应用在任意前台状态下响应。
2. 悬停可高亮光标下的窗口，单击选中整窗；或按住鼠标拖拽框选区域。
3. 松手后工具栏出现：在选区内单击、按 Enter 或双击确认（只复制到剪贴板）；Esc 取消；选区内拖动可移动选区，拖动手柄可调整大小。
4. 工具栏从左到右：形状（点开选矩形 / 椭圆 / 直线 / 箭头）、画笔、文字、马赛克、序号、长截图、识别文字 ｜ 颜色、撤销、保存、贴图、取消、确认。选中工具后在选区内拖动绘制；⌘Z 撤销、⇧⌘Z 重做、⌘S 保存 PNG。
5. 点图钉按钮把当前选区贴成置顶浮窗；拖动贴图移动，滚轮缩放，⌥+滚轮调透明度，Esc 关闭，右键菜单可复制 / 识别文字 / 保存 / 旋转。
6. 菜单「设置…」可改快捷键、工具栏位置、自动保存（默认关闭：开启后每次确认截图都会按模板落盘一份 PNG）与开机自启（默认关闭：开启后登录系统时自动打开）。
7. 长截图：框选区域后点工具栏 ⇕ 按钮，选区会保留一圈蓝框，上方出现采集控制条（显示已拼接高度）；**把鼠标移到页面上**滚动（不要停在控制条上），高度会自动增长；拼够后点「完成」，会弹出「长图已复制 W×H」提示，图已在剪贴板（开启自动保存时同时落盘）。滚动慢一些，太快可能漏行。
8. 剪贴板：在「设置 → 剪贴板」开启后，按 ⌃⌥V（可修改）打开面板；单击只选中，Enter / 双击复制，行内「复制」按钮连续复制不关闭面板；⌥⌫ 删除、⌘⌫ 清空、Esc 关闭。

## 目录结构

```
src/iCut/          Swift 源码（App / Core / Feature）
tests/iCutTests/   单元测试
scripts/           构建与打包脚本
resources/         打包资源（Info.plist）
.github/workflows/ GitHub Actions 构建配置
dist/              构建产物（不入库）
```

## 发布流程

1. 确认 `resources/Info.plist` 的版本号与本次 tag 一致。
2. 推送 tag（如 `v0.1.0`），GitHub Actions 自动构建 universal 包并创建 Release 附件。
3. 其余分支与 PR 的构建只产 artifact，不创建 Release。

### 长截图调试

长截图匹配失败时，可临时打开调试抓帧（默认关闭）：

```bash
defaults write com.icut.app debug.longCaptureDump -bool YES
```

开启后匹配失败的帧会以 PNG 存到 `~/Library/Caches/longshot-debug/`（每次会话最多 20 张），供离线分析为什么衔接不上。排查完用 `defaults delete com.icut.app debug.longCaptureDump` 关掉。
